# Related work and implementation context

Primary sources checked on 25 October 2026 (Asia/Kolkata). These are design context, not datasets reproduced in this project. No published result below is used as a SafeHeal score.

| Source | Relevant idea | Relationship and difference |
|---|---|---|
| [Kubernetes: Controllers](https://kubernetes.io/docs/concepts/architecture/controller/) | Controllers reconcile observed state toward desired state. | A scale-zero fixture has desired zero; native reconciliation is expected to preserve it. Our explicit restoration policy changes desired state under separate authorization. |
| [Kubernetes: RBAC](https://kubernetes.io/docs/reference/access-authn-authz/rbac/) | Authorization can name resources and subresources. | The executor's Role names payment and its scale subresource. RBAC does not constrain the requested replica value; our admission policy adds that restriction. |
| [Kubernetes: Validating Admission Policy](https://kubernetes.io/docs/reference/access-authn-authz/validating-admission-policy/) | CEL policies validate API requests in the API server. | A fail-closed policy independently constrains the dedicated identity's old/new scale values. Controller checks still handle enrollment and durable execution state. |
| Rob Ewaschuk, [Monitoring Distributed Systems](https://sre.google/sre-book/monitoring-distributed-systems/), Google SRE book | Monitoring distinguishes symptoms and causes and combines internal and external observations. | Prometheus symptoms support hypotheses; real confirmed-order checks provide separate business verification. The implementation does not infer causal mechanisms from correlated symptoms. |
| Gan et al., [Sage: Practical & Scalable ML-Driven Performance Debugging in Microservices](https://research.google/pubs/sage-practical-scalable-ml-driven-performance-debugging-in-microservices/), ASPLOS 2021 | Unsupervised models use microservice dependencies for performance diagnosis and corrective actions. | SafeHeal uses a fixed topology, normalized evidence and a bounded ranker; it does not train Sage's models, reproduce its experiments or compare accuracy with it. |
| Chen et al., [AIOpsLab](https://www.microsoft.com/en-us/research/publication/aiopslab-a-holistic-framework-for-evaluating-ai-agents-for-enabling-autonomous-cloud/), MLSys 2025; [implementation](https://github.com/microsoft/AIOpsLab) | An evaluation framework orchestrates microservices, faults, workload, telemetry and agent interactions. | SafeHeal likewise retains full incident episodes, but its recovery scope is deliberately one allowlisted transition. Its small local study is not an AIOpsLab benchmark result. |

The architectural interpretation is our synthesis of these sources. We do not claim that least privilege, structured outputs, fault injection or independent policy enforcement are novel inventions. The contribution is the concrete integration, safety invariants, retained failures and reproducible measurements in this repository.
